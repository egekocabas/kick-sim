# Contributing

Kick Sim is currently published as a showcase and reference implementation. External code contributions and unsolicited pull requests are not being accepted before `v1.0.0`.

Bug reports are welcome through [GitHub Issues](https://github.com/egekocabas/kick-sim/issues). Report security vulnerabilities privately according to the [security policy](SECURITY.md), and follow the [Code of Conduct](CODE_OF_CONDUCT.md) in all project spaces.

The contribution policy will be reviewed when the project reaches `v1.0.0`.
